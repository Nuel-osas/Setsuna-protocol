Run the Next.js frontend locally while reading the deployed Monad mainnet contracts. A local website does not imply test funds: configured wallet transactions settle on mainnet.

## Requirements

Use Node.js 24. Install dependencies from the `setsuna` project directory:

```sh
npm ci
```

## Configure the app

Copy `.env.example` to `.env.local`. Set `SETSUNA_MAINNET_EARN` and `SETSUNA_MAINNET_TRADING` to the public JSON deployment manifests generated by the mainnet Foundry scripts. They contain contract addresses and deployment blocks, never signing keys. See [networks and contracts](/docs/developers/contracts/).

Without these manifests, the affected products remain read-only. There is no fork fallback, faucet or unlocked test account.

```sh
npm run dev
```

Open [the local frontend](http://localhost:3000). Connect a browser wallet or passkey account. Review the network and amounts before signing; this uses real MON, USDC and AUSD.

## Verification

```sh
npm run typecheck
npm run build
npm run test:mainnet
npm run test:earn-keeper
```

Run `npm run contracts:test` for the Foundry contract tests. They use local mocks and require no RPC server. Fork test suites and launchers have been removed. Historical demo transaction records remain in the repository's `docs/research/` directory.

## Keepers

The frontend does not run keepers. Use the separate [keeper service](/docs/developers/keepers/) to record rate observations and trigger valid rebalances on Monad mainnet.
